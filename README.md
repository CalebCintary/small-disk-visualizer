# Disk Visualizer

Небольшое нативное приложение для macOS, которое показывает, чем занят диск: treemap, таблица с сортировкой и разбивка тома на файлы, swap, служебные тома и свободное место.

- Параллельное сканирование с возможностью отмены.
- Символические ссылки не обрабатываются, другие диски не затрагиваются, жёсткие ссылки считаются один раз.
- Результат хранится во временной базе SQLite и удаляется при закрытии приложения.
- Расчёт запускается кнопкой и сохраняется для каждого расположения, пока приложение открыто.

## Установка

Нужны macOS 14 или новее и Apple Silicon.

1. Скачайте архив со страницы [Releases](https://github.com/CalebCintary/small-disk-visualizer/releases) и распакуйте его.
2. Перенесите `Disk Visualizer.app` в «Программы».
3. Приложение не нотаризовано, поэтому при первом запуске снимите карантин:

```bash
xattr -dr com.apple.quarantine "/Applications/Disk Visualizer.app"
```

Чтобы посчитать защищённые папки, выдайте приложению доступ: Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску. Часть системных данных останется закрытой и попадёт в отдельную категорию.

## Сборка

Нужен Xcode.

```bash
./scripts/build-app.sh
```

Готовое приложение появится в `build/Disk Visualizer.app`.
